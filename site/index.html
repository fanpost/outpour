Outpour

Write one long-form article in markdown. Schedule it once. Publish it everywhere.

Outpour is a free, open source tool for writers who post the same article in several places. You write it once, in plain Markdown. Outpour sends it to each site for you, now or at a time you pick, and keeps a list of where every post landed. Run it again after an edit and it updates those posts instead of posting twice.

How it works, in three steps

  • Write once. Your article is one Markdown file, the plain-text format every writing and dev tool already uses.
  • Pick where and when. Choose the platforms, publish now, or set a time: outpour publish post.md --to devto --to nostr-longform --schedule "tomorrow 9am"
  • See the links. Outpour posts everywhere and shows you the live link for each place. If one site fails, you see exactly which one and why.

Connect your favorite editor

Outpour reads plain Markdown files, so it is compatible with every Markdown editor. There is no plugin to install inside your editor. How it connects depends on how the editor stores files:

  • Folder editors connect live. Point Outpour at the folder once and every file in it is ready to publish: Obsidian, VS Code (including Foam), Zettlr, iA Writer, Logseq. The same goes for the content folder of a static site (Hugo, Jekyll, Astro, Eleventy) and for any Git repository of Markdown.
  • Single-file editors connect by import. Write in Typora, MarkText, Ghostwriter, MacDown, Apostrophe, or ReText, or in a plain text editor like Sublime Text, Vim, Neovim, Emacs, or Notepad++, then bring the file in with the import button in the web UI, or drop it into the content folder.
  • Web editors connect by export. HackMD, HedgeDoc, StackEdit, and Dillinger export Markdown; Outpour imports it.
  • Database apps connect one way, by export. Notion, Bear, Ulysses, Scrivener, and Joplin keep notes in their own database rather than as files, so the route is their Markdown export into Outpour's import. Honest limit: that is a one-way trip, not a live sync.
  • AI tools connect directly. Claude Code and other MCP clients publish through Outpour's MCP server. Drafts from ChatGPT or Claude come in as .md files, like any other article.

Quickstart

pip install git+https://github.com/fanpost/outpour
export CRIER_DEVTO_API_KEY=your-devto-key
outpour publish post.md --to devto --draft

Free option: let GitHub run the schedule

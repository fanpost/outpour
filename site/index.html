Outpour

Write one long-form article in markdown. Schedule it once. Publish it everywhere.

Outpour is an open source article scheduler for writers who publish in more than one place. One markdown file with frontmatter is the single source of truth. Outpour fans it out to each platform, records what went where, and never posts the same article twice.

Get Outpour on GitHub

Where it publishes

Dev.to

Full articles with tags, canonical URL and cover image, draft or live.

Nostr (NIP-23)

Native long-form events (kind 30023), signed with your key and sent to your relays. No account approval, no fees, no OAuth.

Medium and Hashnode

Supported through their APIs, with a manual copy-paste fallback for Medium.

WordPress and Ghost

Carried over from the upstream engine, ready when you are.

How it works

  • Write in markdown, describe the article once in frontmatter.
  • Publish now, or schedule for later: outpour publish post.md --to devto --to nostr-longform --schedule "tomorrow 9am"
  • Re-running is safe. The ledger remembers each platform post id, so a retry updates or skips instead of duplicating.
  • Partial failures are reported honestly, per platform, with the live URL of everything that did go out.

Quickstart

pip install git+https://github.com/fanpost/outpour
export CRIER_DEVTO_API_KEY=your-devto-key
outpour publish post.md --to devto --draft

Hosted on GitHub, free

This page is served by GitHub Pages. The scheduler itself can also run on GitHub Actions: this repository carries a scheduled workflow that wakes up every 15 minutes, publishes whatever is due, and commits the publishing state back. No server, no hosting bill.
